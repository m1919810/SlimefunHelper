## 功能列表

该模组提供了一系列特殊的功能为粘液科技游玩和服务器探索与开发方面提供便利

这些功能分为以下若干模块

- 挖掘模块
  - 自动挖掘机器人
  - 快速破坏
  - 挖掘行为优化
  - 发包挖掘
  - 等其他功能
- 聊天模块
  - 聊天助手
  - 聊天框合并
  - 客户端代理指令
  - 命令体系
  - 等其他功能
- 对战模块
  - 自动瞄准
  - 自动攻击
  - tp相关
  - 等其他功能
- 实体渲染模块
  - 实体追踪
  - 抛射物计算
  - 材质包相关
  - 禁用某些效果
  - 等其他功能
- 物品栏模块
  - 快捷物品栏操作
  - 快捷合成操作
  - 箱子界面管理器
  - 物品NBT编辑器
  - 物品数据库
  - 等其他功能
- 移动模块
  - 简易飞行
  - NoFall
  - TP
  - 相关日志
  - 等其他功能
- 网络模块
  - 代理
- 交互模块
  - 还在开发中
- 粘液模块
  - 配方数据库
  - 粘液指南书
  - 多方块助手
- 物品模型模块
  - 粘液材质附加
  - 覆盖物品模型
  - 新风格物品模型
  - 容器物品附加信息显示
  - 等其他功能
