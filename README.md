## 粘液助手

该mod由 m1919810 开发

目前支持1.21.11, 1.21.4, 1.21.1版本

目前所有最新更新均在1.21.11版本

1.20.4以下的版本已经不再更新,可以在release中找到往期旧版本

旨在**为粘液科技和生存提供更多便利和增强游戏与开发体验**

更多功能有待开发

## 安装须知
启动成功后,可以在多人游戏菜单的右上角，

或者在游戏中使用ctrl+G或者使用指令打开配置菜单


其中可以配置所有快捷键和参数

模组指令前缀为!!或者/!!

该模组最新版已经不和锂冲突

**但是旧版本仍旧可能冲突**
