## 安装须知
1. **该Mod不是服务端插件或者模组，请不要把他放到服务端里**


2. 启动成功后,在多人游戏菜单的右上角，或者在游戏中使用右侧Alt或者使用指令!!openmenu clickgui打开ClickGui<br>
如果你的操作系统没有右Alt键, 请使用上述的其他方法进入ClickGui并在其中找到ClickGui模块以修改快捷键


3. ClickGui中可以配置所有快捷键和参数


4. 模组指令前缀为!!或者/!!, 如果该前缀与其他模组产生冲突, 用户可以在ClickGui中的基础设置中修改前缀


5. 模组大部分文字均有语言文件驱动, 用户可以安装汉化包以汉化该模组

## 配置相关
在游戏中输入/!!config load指令, 其便会弹出一行字,提示你需要放入文件. 点击该行字即可打开配置导入的文件夹

将保存的配置文件(后缀名.nbt)放入后使用/!!config load 你文件的名字(可以tab出来即可)  即可加载配置文件

如果想要保存配置文件,输入/!!config save 保存的名字,即可保存。

更多的使用方式输入/!!help config 获取
