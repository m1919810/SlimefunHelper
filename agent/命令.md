# SlimefunHelper 命令系统开发速查

## 核心类

| 类 | 作用 |
|---|------|
| `AbstractMainCommand` | 根命令基类，管理子命令、权限、帮助 |
| `SubCommand` | 子命令接口：`TaskSubCommand`（叶子）、`TreeSubCommand`（容器） |
| `CommandExecution` | 命令执行上下文（玩家/控制台、发消息、权限） |
| `ArgumentInputStream` | 按定义顺序解析参数，提供类型安全读取 |
| `ArgumentReader` | 原始参数迭代器 |
| `SimpleCommandArgs` | 构建参数列表的 DSL |

## 1. 创建根命令

```java
public class MyCmd extends AbstractMainCommand {
public MyCmd() {
setMainName("mycmd");
setPermissionRequired("my.permission"); // 可选
// 注册子命令
registerSub(SubCommand.taskBuilder()
.name("hello")
.helper("打招呼")
.arg(SimpleCommandArgs.argumentBuilder().name("name").build())
.post(e -> e.executor((exec, args, reader) -> {
exec.sendMessage("Hello " + args.nextNonnullString());
return true;
}))
.build());
}
}
```

在 `BaseModule` 中注册：
```java
registerCommandBootstrap(mc -> mc.registerAsCommand(new MyCmd()));
```

## 2. 构建多级子命令（以 `travel` 命令为例）

以下示例展示如何构建 `/travel travel to <coord>` 和 `/travel travel cancel` 两级子命令：

```java
public void bootStrapTravelCommand(MainCommand mainCommand) {
// 创建一级子命令 "travel"
TreeSubCommand main = mainCommand.mainBuilder().name("travel").build();
{
// 在一级命令下创建二级树命令（也是 "travel"），该命令包含两个叶子子命令 "to" 和 "cancel"
main.subBuilder(SubCommand.treeBuilder())
.name("travel")
.post(s -> s.subBuilder(SubCommand.taskBuilder())
.name("to")
.helper("<coord> 自动传送旅行")
.arg(SimpleCommandArgs.argumentBuilder(MovTasks.TpaAndPosArgumentType::new)
.name("target")
.build())
.post(e -> e.executor(this::onTravelTo))
.complete()
.subBuilder(SubCommand.taskBuilder())
.name("cancel")
.helper("中断传送旅行")
.post(e -> e.executor(CommandContext.run(this::onTravelCancel)))
.complete()
)
.complete();
}
}
```

**解释**：
- `mainCommand.mainBuilder().name("travel").build()` 创建了一个名为 `travel` 的一级子命令（`TreeSubCommand`）。
- 在该一级命令上调用 `subBuilder(SubCommand.treeBuilder()).name("travel")` 创建了二级树命令（同样名为 `travel`），这实际上形成了 `/travel travel` 的路径。
- 在二级树命令的 `post` 回调中，通过两次 `subBuilder(SubCommand.taskBuilder())` 分别添加了 `to` 和 `cancel` 叶子命令。
- 最终的命令路径为：`/travel travel to <coord>` 和 `/travel travel cancel`。

## 3. 参数定义（`SimpleCommandArgs.ArgumentBuilder`）

| 方法 | 说明 | 示例 |
|------|------|------|
| `.name(String)` | 参数名 | `.name("count")` |
| `.intValue()` | 整数，默认 tab | `.intValue()` |
| `.intValue(int def)` | 整数带默认值 | `.intValue(10)` |
| `.floatValue()` | 浮点数 | `.floatValue()` |
| `.bool()` | 布尔，tab true/false | `.bool()` |
| `.select("a","b")` | 固定选项 | `.select("opt1","opt2")` |
| `.enumValue(Class)` | 枚举 | `.enumValue(MyEnum.class)` |
| `.tabSupplier(() -> stream)` | 自定义 tab | `.tabSupplier(() -> playerNames.stream())` |
| `.defaultValue(String)` | 默认值 | `.defaultValue("0")` |

## 4. 参数读取（`ArgumentInputStream`）

在命令执行器内：
```java
.post(e -> e.executor((exec, args, reader) -> {
int i = args.nextInt();
double d = args.nextDouble();
boolean b = args.nextBoolean();
String s = args.nextNonnullString();
MyEnum e = args.nextEnum(MyEnum.class);
String selected = args.nextSelect(List.of("a","b"));
Integer opt = args.nextArg();          // 可空
int clamped = args.nextClampedInt(0, 100);
return true;
}))
```

## 5. 命令执行上下文（`CommandExecution`）

常用方法：
- `getExecutor()` – 玩家或 null
- `isPlayer()` – 是否玩家
- `getExecutorPlayer()` – 强制获取玩家（非玩家抛异常）
- `sendMessage(String)` – 支持 & 颜色码
- `hasPermission(String)` – 权限检查

## 6. 错误处理（内置异常，自动捕获提示）

| 异常 | 触发 |
|------|------|
| `TypeError` | 类型不匹配 |
| `ValueAbsentError` | 缺少必需参数 |
| `ValueOutOfRangeError` | 数值超范围 |
| `InvalidExecutorError` | 玩家/控制台限制 |
| `PermissionDenyError` | 权限不足 |
| `LogicalError` | 自定义逻辑错误 |

手动抛异常：
```java
checkArgument(condition, "错误信息");
checkNonnull(obj, "不能为空");
```

                            .name("cancel")
                            .helper("中断传送旅行")
                            .post(e -> e.executor(CommandContext.run(this::onTravelCancel)))
                            .complete()
                    )
                    .complete();
        }
    }

    private boolean onTravelTo(CommandExecution exec, ArgumentInputStream args, ArgumentReader reader) {
        // 实现传送逻辑
        return true;
    }

    private void onTravelCancel() {
        // 实现取消逻辑
    }
}
