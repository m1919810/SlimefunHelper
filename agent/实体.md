# Minecraft 实体运动系统文档

本文档基于对 Minecraft 源代码（`net.minecraft.entity` 包及相关子包）中实体运动相关核心类的分析，总结了实体运动系统的整体架构、关键流程和核心方法。重点关注 `LivingEntity` 及其子类（如 `PlayerEntity`）的运动机制。

## 1. 运动基础：Entity 类

`Entity` 是所有实体的基类，定义了最基础的位置、速度、移动和碰撞逻辑。

### 1.1 位置与速度

- **位置**：`pos`（`Vec3d`），通过 `setPos()` 更新。同时维护 `lastX, lastY, lastZ` 用于插值。
- **速度**：`velocity`（`Vec3d`），通过 `setVelocity()` 修改。`velocityDirty` 标记表示速度需要同步。
- **重力**：`getGravity()` 返回 0（由子类重写），`getFinalGravity()` 结合 `NoGravity` 标志返回实际重力值。
- **移动**：`move(MovementType type, Vec3d movement)` 是核心移动方法，处理碰撞、活塞移动、潜行调整等。

### 1.2 移动流程 (`move` 方法)

```java
public void move(MovementType type, Vec3d movement) {
    // 无碰撞模式直接设置位置
    // 否则：
    // 1. 处理活塞移动调整
    // 2. 根据潜行调整移动向量
    // 3. 调用 adjustMovementForCollisions 计算最终移动向量
    // 4. 更新位置，记录碰撞状态（水平/垂直碰撞）
    // 5. 处理落地、步声音效等
}
adjustMovementForCollisions：基于边界框和世界中的碰撞箱计算实际可移动的距离。

adjustMovementForSneaking：潜行时处理边缘防掉落逻辑。

碰撞后设置 horizontalCollision, verticalCollision, onGround 等标志。

1.3 移动输入与速度应用
updateVelocity(float speed, Vec3d movementInput)：根据移动方向、速度和当前偏航角计算出加速度并加到速度上。

movementInputToVelocity：静态方法，将输入向量转换为世界坐标系下的速度增量。

1.4 重力应用
在 baseTick() 中不会直接应用重力，重力通常在 travel() 或 move() 中通过速度变化隐式应用。子类（如 LivingEntity）会重写 travel() 并显式减去重力值。

2. 生物运动：LivingEntity 类
LivingEntity 继承 Entity，增加了生命值、状态效果、装备等，并实现了更复杂的运动逻辑，包括跳跃、游泳、滑翔、攀爬等。

2.1 核心运动方法 travel(Vec3d movementInput)
这是 LivingEntity 中最重要的运动入口，根据当前状态分发到不同的运动处理逻辑：

java
public void travel(Vec3d movementInput) {
    if (this.isTravellingInFluid(fluidState)) {
        this.travelInFluid(movementInput);
    } else if (this.isGliding()) {
        this.travelGliding(movementInput);
    } else {
        this.travelMidAir(movementInput);
    }
}
travelInFluid：处理在水或岩浆中的运动。

travelGliding：处理鞘翅滑翔。

travelMidAir：标准的地面/空中运动（包括跳跃、下落等）。

2.2 标准运动：travelMidAir
java
private void travelMidAir(Vec3d movementInput) {
    // 获取脚下的摩擦力
    float slipperiness = this.isOnGround() ? getBlockSlipperiness() : 1.0F;
    float friction = slipperiness * 0.91F;
    // 应用输入和摩擦力得到新速度
    Vec3d newVelocity = this.applyMovementInput(movementInput, slipperiness);
    double yMotion = newVelocity.y;
    // 处理飘浮效果或重力
    if (hasLevitation) {
        yMotion += (0.05 * (amplifier+1) - yMotion) * 0.2;
    } else {
        yMotion -= this.getEffectiveGravity();
    }
    // 应用摩擦（空中摩擦系数0.98，地面根据摩擦力）
    this.setVelocity(newVelocity.x * friction, yMotion * (this.noDrag ? 1.0 : 0.98), newVelocity.z * friction);
}
applyMovementInput：根据输入和当前速度更新速度，并调用 move() 移动。

重力通过 getEffectiveGravity() 获得（考虑缓慢下落效果）。

摩擦力：地面摩擦力取决于脚下方块，空中摩擦力固定 0.98。

2.3 流体运动：travelInFluid → travelInWater / travelInLava
在水/岩浆中移动速度较慢，且有浮力（通过修改 Y 轴速度）。

调用 updateVelocity 加速，然后 move，最后乘以阻力系数（水：0.8，岩浆：0.5）。

通过 applyFluidMovingSpeed 处理流体阻力与重力的平衡。

2.4 滑翔：travelGliding
仅在装备鞘翅且在空中时触发。

计算基于俯仰角的滑翔速度向量，更新速度并移动。

碰撞到墙壁会触发伤害。

2.5 跳跃
java
public void jump() {
    float jumpVelocity = this.getJumpVelocity(); // 基于 JUMP_STRENGTH 属性
    Vec3d vel = this.getVelocity();
    this.setVelocity(vel.x, Math.max(jumpVelocity, vel.y), vel.z);
    if (this.isSprinting()) {
        // 增加冲刺时的水平速度
        float yawRad = this.getYaw() * 0.017453292F;
        this.addVelocityInternal(new Vec3d(-MathHelper.sin(yawRad) * 0.2, 0.0, MathHelper.cos(yawRad) * 0.2));
    }
    this.velocityDirty = true;
}
跳跃强度由属性 JUMP_STRENGTH 决定，加上跳跃提升效果加成。

在 tickMovement() 中，如果 jumping 标志为真且满足条件（在地面或流体中），则调用 jump()。

2.6 攀爬
isClimbing() 检测脚下是否为 CLIMBABLE 方块（梯子、藤蔓等）或开启的活板门+梯子组合。

在 applyClimbingSpeed 中限制水平和垂直速度（最大 0.15），使实体能附着攀爬。

2.7 属性对运动的影响
LivingEntity 使用属性（Attributes）控制运动相关数值：

MOVEMENT_SPEED：基础移动速度。

JUMP_STRENGTH：跳跃强度。

GRAVITY：重力大小。

SAFE_FALL_DISTANCE：安全下落距离。

FALL_DAMAGE_MULTIPLIER：摔落伤害倍率。

STEP_HEIGHT：自动走上的台阶高度。

WATER_MOVEMENT_EFFICIENCY：水中移动效率。

MOVEMENT_EFFICIENCY：影响速度乘数（如雪地减速）。

2.8 其他重要方法
tickMovement()：每 tick 调用，处理输入（侧向/向前速度衰减）、跳跃、滑翔、挤压伤害等。

updateVelocity(float speed, Vec3d movementInput)：将输入转换为速度增量。

setMovementSpeed(float) / getMovementSpeed()：控制 AI 移动速度。

3. 玩家运动：PlayerEntity
PlayerEntity 继承 LivingEntity，添加了玩家特有的运动逻辑，如飞行、冲刺、自动跳跃、骑乘控制等。

3.1 飞行模式
abilities.flying 标志控制是否飞行。

在 travel() 中，如果飞行，则使用飞行速度（abilities.getFlySpeed()）移动，且重力不生效。

飞行时按住跳跃键上升，潜行键下降。

3.2 冲刺
通过 setSprinting 设置，并修改移动速度属性（增加 0.3 倍乘法修正）。

冲刺时速度更快，且跳跃时获得水平加速度。

3.3 自动跳跃
客户端 ClientPlayerEntity 实现 autoJump 逻辑，当玩家靠近一个可自动跳上的台阶时，自动触发跳跃。

通过射线检测和碰撞箱计算决定是否跳起。

3.4 骑乘控制
重写 travelControlled，在骑乘时通过 getControlledMovementInput 获取玩家的输入，并调用 tickControlled。

对于可控制坐骑（如马、船），将输入传递给坐骑。

3.5 攻击冷却与移动
攻击速度影响冷却，但不直接影响移动速度。getAttackCooldownProgress 用于攻击伤害系数。

3.6 客户端移动预测
ClientPlayerEntity 负责处理客户端的本地移动预测和向服务器发送移动数据包：

tickMovement() 中根据本地输入更新位置，然后调用 sendMovementPackets() 发送位置/旋转变化。

比较本地位置与上次发送位置的差异，只在变化超过阈值或间隔超过 20 tick 时发送完整数据包。

处理自动跳跃、飞行切换、鞘翅滑翔启动等。

4. 运动状态机
实体运动受到多种状态影响，状态在 tickMovement 中根据条件切换：

状态	触发条件	行为
在水/岩浆中	isTouchingWater() 或 isInLava()	阻力增大，浮力，可游泳
滑翔	isGliding() 且装备鞘翅	特殊滑翔物理，按俯仰角改变速度
攀爬	isClimbing()	速度受限，可上下移动
潜行	玩家按下潜行键或自动潜行姿态	速度降低，防掉落边缘
飞行 (创造/旁观)	abilities.flying	无重力，可自由升降
骑乘	hasVehicle()	移动由坐骑控制或输入转发
睡觉	isSleeping()	无法移动
5. 运动相关数据同步
服务器：LivingEntity 通过 sendEquipmentChanges() 等发送装备变更，但不直接发送每 tick 位置。位置同步由 EntityTrackerEntry 负责，定期向客户端发送位置更新。

客户端：ClientPlayerEntity 主动发送移动数据包；其他实体通过服务器下发的 EntitySpawnS2CPacket 和后续的 EntityPositionS2CPacket 更新位置，客户端使用 PositionInterpolator 进行平滑插值。

6. 关键代码路径总结
玩家输入 → ClientPlayerEntity.tickMovement() → 更新 input → 调用 travel() → 更新本地位置 → 发送 PlayerMoveC2SPacket。

服务器接收 → ServerPlayNetworkHandler 处理移动包 → 调用 PlayerEntity.move() → 碰撞检测 → 更新服务器位置 → 广播给附近玩家。

AI 生物 → MobEntity.tickMovement() → updateVelocity() → travel() → 移动 → 导航更新。

物理计算 → Entity.adjustMovementForCollisions() → 获取碰撞箱 → 计算位移 → 应用摩擦力/重力。

以上是对 Minecraft 实体运动系统的整体总结。核心思想是通过统一的 move() 方法处理碰撞，派生类通过重写 travel() 实现不同环境下的运动物理，并通过属性系统灵活调整运动参数。
