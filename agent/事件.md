
# SlimefunHelper 事件监听通道文档

## Event 类说明

所有事件回调都接收 `Event<T>` 对象，该类提供以下核心方法：

| 方法 | 说明 |
|------|------|
| `T context()` | 获取事件主体（如攻击事件中的 `HitResult`） |
| `Event<T> context(T val)` | 修改事件主体（需要 `canModifyContext` 为 true） |
| `boolean isCancelled()` | 检查事件是否已被取消 |
| `Event<T> cancel()` | 取消事件（需要 `canCancel` 为 true） |
| `<W> W getArgs(int idx)` | 获取额外参数（按声明顺序索引） |
| `boolean canCancel()` | 是否允许取消 |
| `boolean canModifyContext()` | 是否允许修改主体 |

> **重要约定**：同一 `EventChannel` 的 `canCancel` 和 `canModifyContext` 属性是**固定的**，已在通道定义处的注解（如 `@Cancelable`、`@Modifiable`）中明确声明。开发者在处理事件时**不应修改这些标志**，也**无需显式调用 `canCancel()` 或 `canModifyContext()` 进行判断**，除非需要根据是否允许取消/修改来执行不同的分支逻辑（例如只在可取消时尝试取消）。通常情况下，您可以直接调用 `cancel()` 或 `context(val)`，如果通道不允许该操作，调用会抛出异常（由框架保证）。但为了代码健壮性，在不确定通道定义时可以先调用对应的 `canXxx()` 方法检查。

**使用示例**：

```java
private void onGameRender(Event<GameRenderer> event) {
RenderTickCounter tickCounter = event.getArgs(0);
boolean isRenderWorld = event.getArgs(1);
// 该通道被标记为 @Cancelable，所以可以直接取消
if (someCondition) {
event.cancel();
}
}

private void onChatSend(Event<String> event) {
// 该通道被标记为 @Modifiable，所以可以直接修改
if (event.canModifyContext()) { // 可选检查，但通常直接调用即可
event.context("[Prefix] " + event.context());
}
}
```

## 事件通道访问规范

**所有事件通道（包括 `Listener` 和 `RenderListener` 中的通道）都必须通过对应的 `getter` 方法访问**，禁止直接访问静态字段。

| 类 | 正确方式 | 错误方式 |
|---|----------|----------|
| `Listener` | `Listener.getPostGameTick()` | `Listener.postGameTick` |
| `Listener` | `Listener.getPacketPoint()` | `Listener.packetPoint` |
| `RenderListener` | `RenderListener.getRenderLayerTasks()` | `RenderListener.renderLayerTasks` |

**注册示例**：
```java
// 基础事件
registerListener(Listener.getPostGameTick(), this::onTick);
registerListener(RenderListener.getRenderLayerTasks(), this::onRender);

// 精确网络包事件（避免使用 getPacketSendPoint/getPacketAcceptPoint）
registerListener(Listener.getPacketPoint().getChannel(PlayerInteractBlockC2SPacket.class), this::onInteractBlock);
```

## 使用示例

```java
// 在 BaseModule 子类中
@Override
public void registerAll() {
super.registerAll();
// 监听后游戏 tick
registerListener(Listener.getPostGameTick(), this::onPostGameTick);
// 监听攻击动作（高优先级）
registerListener(Listener.getAttackAction(), this::onAttack, -999);
// 精确监听特定包
registerListener(Listener.getPacketPoint().getChannel(PlayerInteractBlockC2SPacket.class), this::onInteractBlock);
}
```
