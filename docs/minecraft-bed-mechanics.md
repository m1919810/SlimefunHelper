# Minecraft 床机制（Java Edition 1.21.11）

本文聚焦 Java Edition。Bedrock Edition 的交互和规则不在本文范围内。1.21.11 将旧维度类型字段 `bed_works` 替换为 `minecraft:gameplay/bed_rule` 环境属性。该属性在床头位置解析，因此自定义维度或生物群系也可能影响同一维度内不同位置的床行为。

## 床的结构与放置

床是占据两个水平相邻方块位置的方块，不是单格方块。它由两个方块状态组成：

- `part=foot`：床尾，也是通常放置时靠近玩家的一端。
- `part=head`：床头，沿 `facing` 方向与床尾相邻。
- `facing`：床的朝向；床的长度沿此方向延伸。
- `occupied`：床是否正在被玩家占用。

放置床时，游戏会根据玩家朝向确定床的朝向，并同时检查床尾和床头两个目标位置能否放入床。任一位置不适合放置时，整张床都不能放下；成功后两格作为一张床同步存在。两格目标位置都必须满足游戏的方块放置判定。放置床本身不会引发爆炸。

破坏床的任意一半都会移除整张床；掉落行为受破坏方式及游戏规则影响。需要追踪床的位置时，应把 `head` 和 `foot` 视为一个整体，并保留床头、床尾与朝向的关系。

## 睡眠与重生点

玩家在允许睡觉的维度与时段使用床时，服务器会检查玩家是否能入睡，例如床是否被占用、附近是否有阻止睡觉的敌对生物，以及是否处于允许睡眠的时间。成功睡觉会推进夜晚，并尝试设置个人重生点；不能睡觉时，游戏会向玩家反馈原因。多人游戏中，一名玩家睡觉是否足以跳过夜晚，还受睡觉玩家比例等游戏规则影响。

“能否睡觉”“能否设置重生点”“使用床是否爆炸”是三个不同的行为，不应只用旧版 `bed_works` 一个布尔值概括。1.21.11 的 `minecraft:gameplay/bed_rule` 对象包含 `can_sleep`、`can_set_spawn`，以及可选的 `explodes` 和 `error_message`：

- `can_sleep` / `can_set_spawn` 可分别设为 `always`、`when_dark` 或 `never`。`when_dark` 表示全局天空光照等级小于等于 11 时才允许。
- `explodes: true` 表示与床交互时爆炸；省略时默认为 `false`。
- 默认规则是 `can_sleep: when_dark`、`can_set_spawn: always`，并使用标准的无法睡觉提示文本。具体床头位置上的最终值还可能受环境属性覆盖影响。

成功设置重生点后，玩家死亡时会尝试在床附近生成。若床已被破坏、床周围没有可用的重生位置，或该位置不安全，重生可能失败并回退到世界出生点；游戏会提示床缺失或被阻挡。重生点属于玩家，不代表床被锁定给该玩家。

## 床爆炸

### 触发条件

床爆炸是“使用床”时触发的行为，不是放置床时触发。若床头位置解析出的 `bed_rule` 启用了 `explodes`，玩家与床交互会引发爆炸，而不会按普通睡觉流程休息。香草下界和末地使用床会爆炸；自定义维度或生物群系则以床头位置的实际规则为准。爆炸、睡觉和设置重生点由规则中的独立字段控制。

### 爆炸参数和影响

1.21.11 的床爆炸由 `BedBlock.onUse` 发起，关键参数为：

- 爆炸威力 `power = 5.0`。
- 请求生成火焰（`createFire = true`）；最终是否出现火焰还取决于周围方块和放置条件。
- 爆炸位置取床头部分的位置。
- 爆炸来源类型为 `BLOCK`，方块破坏遵循对应爆炸规则及游戏规则。

威力 5.0 不是固定的方块破坏半径或玩家受伤值。实际地形破坏会受方块抗爆性、爆炸行为和相关游戏规则影响；实体伤害与击退还取决于距离、爆炸遮挡、实体碰撞箱及伤害减免。床爆炸与重生锚爆炸的威力相同，但触发交互和源方块不同。详细计算见 [爆炸分析](minecraft-explosion-analysis.md) 与 [玩家伤害计算](player-damage-calculation.md)。

## 实战检查清单

1. 先确认你玩的 Edition 与版本；本文结论针对 Java Edition 1.21.11。
2. 放置前检查床尾、床头两格空间及朝向；放置动作本身不会炸床。
3. 右键床前确认当前维度的床规则，尤其是自定义维度；下界和末地不要把右键当成安全的“尝试睡觉”。
4. 评估爆炸风险时检查床头附近的遮挡、抗爆方块、周围可燃/可放置火焰的空间，以及玩家与爆炸源的距离。
